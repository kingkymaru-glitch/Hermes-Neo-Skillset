# Proposal Structure Reference

Mandatory sections for technical proposals:

1. Executive Summary — 1 page max
2. Company Profile — legal entity, team, certifications, references
3. Technical Proposal — requirement mapping, pipeline, challenges, architecture
4. Equipment Datasheets — table format with purpose/specs/integration
5. Cost Estimation — POC + Full Scale, CAPEX + OPEX
6. Timeline — phased delivery plan
7. Case Study — prior experience with metrics
8. Commercial Information — model, payment terms, support
9. Deliverables — checklist
10. Upgrade Path — future capabilities
11. Appendix — supporting docs
