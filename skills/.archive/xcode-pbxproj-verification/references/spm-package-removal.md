# Worked example: removing GoogleSignIn-iOS from an Xcode pbxproj

Context: AnglerGO iOS app (SwiftUI, Supabase email/password auth). Founder rolled back
all OAuth, so the `GoogleSignIn` + `GoogleSignInSwift` SPM packages had to be unlinked
from `AnglerGo.xcodeproj/project.pbxproj`, leaving only `supabase-swift` + `firebase-ios-sdk`.

## The six places (exact tokens removed)

Product UUIDs (one per exported product):
- `F32892E52FEF89A300A92EA7 /* GoogleSignIn */`
- `F32892E72FEF89A300A92EA7 /* GoogleSignInSwift */`
Parent package UUID:
- `F32892E42FEF89A300A92EA7 /* XCRemoteSwiftPackageReference "GoogleSignIn-iOS" */`
BuildFile UUIDs:
- `F32892E62FEF89A300A92EA7 /* GoogleSignIn in Frameworks */`
- `F32892E82FEF89A300A92EA7 /* GoogleSignInSwift in Frameworks */`

1. **PBXBuildFile** (2 lines) — deleted both `… in Frameworks */ = {isa = PBXBuildFile; …};` lines.
2. **PBXFrameworksBuildPhase** `files = (` — deleted the 2 `UUID /* … in Frameworks */,` entries.
3. **XCSwiftPackageProductDependency** — deleted the 2 product blocks:
   `UUID /* GoogleSignIn */ = {isa = XCSwiftPackageProductDependency; package = F32892E42…; productName = GoogleSignIn; };`
   and the `GoogleSignInSwift` twin.
4. **PBXNativeTarget.packageProductDependencies = (** — removed the 2 product UUIDs from the list.
5. **XCRemoteSwiftPackageReference** — deleted the `F32892E42… "GoogleSignIn-iOS"` block.
6. **PBXProject.packageReferences = (** — removed `F32892E42…` from the list.

## Integrity evidence (ad-hoc static, NOT a build)
- `grep -o '{' | wc -l` == `grep -o '}' | wc -l` → 124 / 124 (committed baseline 130/130;
  delta 6 = 3 balanced blocks removed: 2 PBXBuildFile + the XCRemoteSwiftPackageReference block;
  the 2 PBXFrameworks list entries + 2 packageProductDependencies list entries carry no braces).
- `grep -q GoogleSignIn project.pbxproj` → empty (0 hits).
- `supabase-swift` and `firebase-ios-sdk` still present in packageReferences / product deps.
- `Package.resolved`: regenerated by Xcode 26; `grep -q '"GoogleSignIn-iOS"'` → empty.
- Done via targeted per-line `patch` (full `UUID /* comment */` anchor), NOT a broad substring script.

## What went wrong first (the lesson)
A broad Python `str.replace`/regex that stripped every line containing "GoogleSignIn" ALSO
deleted the `supabase-swift` `XCRemoteSwiftPackageReference` block and desynced brace balance
(130 → unbalanced). Recovery: `git checkout -- AnglerGo.xcodeproj/project.pbxproj`, then
re-applied the six removals surgically with exact-line patches. Takeaway: anchor on the full
`UUID /* comment */` token; `git diff` after every edit; never hand-fix a brace-desynced pbxproj.

## Leftover harmless artifacts
`Resources/GoogleService-Info.plist` remains on disk (still referenced by PBXResourcesBuildPhase
because FirebaseAuth/Firestore/Storage are still linked). Removing Firebase is a separate pass.
Transitive Google deps in Package.resolved (abseil, gtm-session-fetcher, etc.) are firebase
leftovers, unimported, pruned by Xcode on next resolve — ignore them.
